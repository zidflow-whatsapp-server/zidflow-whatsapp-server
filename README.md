# ZidFlow WhatsApp Automation Server

خادم واتساب مجاني 100% يعمل 24/7 على Render.com

## المميزات
- ✅ مجاني بالكامل على Render.com
- ✅ لا يحتاج لأي خدمات خارجية
- ✅ يرسل رسائل واتساب تلقائياً
- ✅ إعادة اتصال تلقائية عند الانقطاع
- ✅ صفحة QR Code لربط هاتفك

## الاستخدام

### ربط الواتساب:
1. افتح رابط الخادم + `/qr`
2. امسح الـ QR Code من هاتفك

### إرسال رسالة:
```
POST /send
{
  "to": "213XXXXXXXXX",
  "message": "مرحباً!",
  "secret": "YOUR_SECRET"
}
```
